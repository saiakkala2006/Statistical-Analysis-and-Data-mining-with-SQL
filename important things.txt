Project: Statistical Analysis and Data Mining with SQL (26sqlll)
1. Abstract

The Statistical Analysis and Data Mining with SQL project is a database-driven analytical system developed using PostgreSQL and Flask. The primary objective of the project is to perform statistical computations, identify hidden patterns, and generate meaningful insights from structured datasets using SQL queries. The system includes SQL functions, views, nested queries, and join operations to perform statistical analysis, trend analysis, and outlier detection. A web interface was developed using Flask, HTML, CSS, and JavaScript, allowing users to view predefined SQL queries and execute them dynamically with real-time results fetched directly from the PostgreSQL database.

10. Novelty of the Project

The uniqueness of this project lies in integrating SQL analytics with a web application.

Unlike conventional SQL projects that require manual execution inside pgAdmin, this project enables users to:

Execute SQL queries directly through a browser.
View both the SQL query and its output with a single click.
Perform statistical analysis and data mining interactively.
Use automatically generated realistic datasets for testing.
Access all analytical features through a clean Flask-based interface.







"Why did you use Flask?"

"I used Flask because it is a lightweight Python web framework that integrates seamlessly with PostgreSQL using psycopg2. It allowed me to create a simple web interface where users can execute predefined SQL queries and retrieve live results from the database without directly interacting with pgAdmin."

"Why PostgreSQL instead of MySQL?"

"PostgreSQL provides advanced analytical functions such as percentile_cont(), window functions, and better support for statistical computations. These features made it more suitable for implementing statistical analysis and data mining operations compared to MySQL."
